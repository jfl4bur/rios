=== TROUBLESHOOTING: EPERM unlink sharp DLL on Windows ===
Si durante `npm --prefix backend ci` ves un error EPERM sobre un archivo dentro de `backend\\node_modules\\sharp\\build\\Release`, prueba lo siguiente:

1) Asegúrate de que no tengas un proceso usando ese archivo (editores, VSCode, un servidor en ejecución, o un antivirus). Cierra VSCode y servidores.
2) Intenta reiniciar el Explorador de Windows o reiniciar el equipo.
3) Intenta eliminar manualmente la carpeta `backend\\node_modules\\sharp\\build\\Release` y volver a ejecutar la instalación:
   Remove-Item -Path .\\backend\\node_modules\\sharp\\build -Recurse -Force
   npm --prefix backend install
4) Si el problema continúa, mueve `sharp` a `optionalDependencies` (ya aplicado en el package.json) y vuelve a ejecutar el script. En ese caso `sharp` no es obligatorio para correr tests locales que no manipulen imágenes.

Si necesitas ayuda, pega aquí la salida completa del error y te doy los comandos exactos para desbloquear el archivo.
